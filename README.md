# Weave - Stock Management System

A modern, secure Stock Management System built with PHP and Bootstrap 5.

## 🛠️ Tech Stack
- **Backend:** PHP (with prepared statements)
- **Frontend:** Bootstrap 5, Lucide Icons, Inter Font
- **Database:** MySQL
- **Styles:** Custom Design Token System (CSS Variables)

## 🔒 Security Features
- SQL Injection protection via Prepared Statements
- CSRF Token validation on forms
- Secure session handling (Session regeneration)
- Environment variable support for credentials
